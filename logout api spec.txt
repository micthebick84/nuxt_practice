
  구현된 로그아웃 엔드포인트

  1. /api/auth/logout (POST) - JSON Body 방식

  // 클라이언트 예시 (JavaScript)
  fetch('http://localhost:9000/api/auth/logout', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      token: 'your-access-token-or-refresh-token',
      tokenTypeHint: 'access_token'  // 선택: 'access_token' 또는 'refresh_token'
    })
  });

  2. /api/auth/logout/bearer (POST) - Authorization Header 방식

  // 더 간편한 방식
  fetch('http://localhost:9000/api/auth/logout/bearer', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer your-access-token'
    }
  });

  3. /oauth2/revoke (POST) - 표준 OAuth2 Token Revocation (RFC 7009)

  // OAuth2 표준 방식 (client_id, client_secret 필요)
  fetch('http://localhost:9000/oauth2/revoke', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/x-www-form-urlencoded',
      'Authorization': 'Basic ' + btoa('client_id:client_secret')
    },
    body: 'token=your-token&token_type_hint=access_token'
  });

  4. /connect/logout - OIDC RP-Initiated Logout

  브라우저에서 사용자를 리다이렉트하여 세션 기반 로그아웃:
  http://localhost:9000/connect/logout?id_token_hint=xxx&post_logout_redirect_uri=http://localhost:3000

  응답 형식

  {
    "success": true,
    "message": "로그아웃 완료",
    "data": {
      "revoked": true,
      "message": "모든 토큰이 무효화되었습니다"
    }
  }




 /connect/logout은 OIDC RP-Initiated Logout 엔드포인트입니다.

  API Spec

  Endpoint

  GET /connect/logout

  Request Parameters

  | 파라미터                 | 필수 | 설명                                                           |
  |--------------------------|------|----------------------------------------------------------------|
  | id_token_hint            | 권장 | 로그인 시 받은 ID Token. 사용자 식별 및 클라이언트 검증에 사용 |
  | post_logout_redirect_uri | 선택 | 로그아웃 후 리다이렉트할 URI. 클라이언트에 등록된 URI여야 함   |
  | state                    | 선택 | CSRF 방지용 상태 값. 리다이렉트 시 그대로 반환됨               |
  | client_id                | 선택 | id_token_hint 없을 때 클라이언트 식별용                        |

  Example Request

  GET /connect/logout?
      id_token_hint=eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...
      &post_logout_redirect_uri=http://localhost:3000/login
      &state=abc123

  Response

  - 성공 시: post_logout_redirect_uri로 302 리다이렉트
  - 실패 시: /error 페이지로 리다이렉트

  등록된 post_logout_redirect_uris (nuxt-app)

  http://localhost:3000/login?logout=true
  http://localhost:3000/login
  http://localhost:3000/

  주의사항

  1. id_token_hint의 서명이 서버의 RSA 키로 검증 가능해야 함
  2. post_logout_redirect_uri가 클라이언트에 등록되어 있어야 함
  3. ID Token이 만료되어도 로그아웃은 처리됨 (서명만 유효하면 됨)
