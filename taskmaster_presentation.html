5️⃣ Sub-Agent 상태 업데이트

문제 발견

모든 작업 완료 후에도 tasks.json에 "status": "pending"으로 표시

해결 방법


"task-master 작업 상황을 업데이트하는
 sub-agent를 만들어줘"

Sub-Agent 실행 과정

Before:


{
  "id": 1,
  "title": "데이터베이스 스키마",
  "status": "pending"
}

After:


{
  "id": 1,
  "title": "데이터베이스 스키마",
  "status": "completed"
}
